O Gerenciador de estoque foi desenvolvido em python com Tkinter para facilitar o controle de
Produtos. O programa permite cadastrar, pesquisar, editar, excluir e visualizar os produtos cadastrados.

Também foram adicionadas algumas validações para evitar dados incorretos e mensagens para informar o usuário sobre ações realizadas. Os produtos são salvos em um arquivo JSON, fazendo com que continuem disponíveis mesmo depois de fechar o programa.

Para utilizar o sistema, é necessário ter o Python instalado e executar o arquivo do projeto. As principais tecnologias utilizadas foram Python, Tkinter e JSON.
